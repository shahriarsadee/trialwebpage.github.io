# Shahriar Sadee Academic Portfolio

A GitHub Pages-ready academic/professional portfolio inspired by the clean, content-first structure of AcademicPages-style sites. The referenced Riasat Morshed Khan page uses clear separate navigation for publications, talks, teaching, courses and portfolio; this version adapts that idea to Shahriar's requested sections.

## Main sections
- Home / profile
- Work Experience
- Portfolio
- Research Works
- Publications
- Communication details

## Files
- `index.html` = main page
- `style.css` = design
- `script.js` = mobile navigation
- `portfolio/` = practical project pages
- `research/` = research pages
- `assets/images/` = photos and figures
- `assets/documents/` = CV and PDFs

## Add your photo
Upload your photograph as `assets/images/profile.jpg`.

## Add your CV
Upload `Shahriar-Sadee-CV.pdf` to `assets/documents/`.

## Update contact details
In `index.html`, search `BLOCK 06: COMMUNICATION` and replace the placeholder email, LinkedIn and GitHub values.

## Add experience
Search `BLOCK 02: WORK EXPERIENCE`, copy an existing `<article>` and edit it.

## Add projects
Search `BLOCK 03: PORTFOLIO`. Add a card and create a detailed HTML page inside `portfolio/` if needed.

## Add research
Search `BLOCK 04: RESEARCH WORKS`. Add only accurate, verifiable work.

## Add publications
Search `BLOCK 05: PUBLICATIONS`. Add verified papers, DOI or official links only. No publications are invented in this template.

## Change colors
Open `style.css` and edit the variables at the top: `--green`, `--dark`, `--light`, `--cream`, `--ink`.

## GitHub Pages
Create a repository named `YOUR-USERNAME.github.io`, upload the contents of this folder so `index.html` is in the repository root, then go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

The structure is intentionally expandable for future talks, presentations, awards, certificates, publications, conference papers, blog posts and additional research projects.
